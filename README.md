# Terminal portfolio

Personal developer portfolio styled as a terminal session. Tabs open "files"
(`about.md`, `projects.ts`, `history.log`, `contact.sh`) and the output types
itself out. A live prompt at the bottom accepts commands such as `help`,
`projects` and `copy`.

A single self-contained `index.html`: no build step and no dependencies apart
from one Google Fonts stylesheet. Open the file in a browser, or serve the
folder with any static host (GitHub Pages works as is).
